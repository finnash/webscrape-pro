# Medium Snapshot — Test Matrix

The Medium snapshot is the flagship orchestration: keyword → discovery → scrape (with Wayback paywall fallback) → AI summary → rich UI cards + downloads.

## How it runs (under the hood)

1. **search_web** — `site:medium.com {keyword}` via Firecrawl `/search` (limit configurable).
2. **scrape_url** — fans out N URLs at concurrency 3, formats `[markdown, summary]`, `onlyMainContent=true`.
3. **paywall fallback** — if returned markdown < 600 chars OR matches `/member-only|paywall|subscribe to read|sign in to continue/i`, the engine queries `https://archive.org/wayback/available?url=...` and re-scrapes the closest snapshot. The card surfaces an "Archive" badge so you know the source.
4. **summarize** — Gemini 3 Flash receives up to ~60K chars of source markdown and emits structured MD with takeaways, quotes, theme grouping, and a Top-5 must-reads ranking.
5. **Persist** — writes `result.items[]`, `result.summary`, `result.searchResults[]` to `snapshot_runs` and flips status to `succeeded`.

Live progress is streamed to the UI via Supabase realtime on `snapshot_runs`.

## Card UI checklist (per item)

- [ ] Title + URL + external link icon
- [ ] Author chip (when present)
- [ ] Read time (computed from word count, 220 wpm)
- [ ] Word count + image count badges
- [ ] "Archive" badge when sourced via Wayback
- [ ] **Copy format** button — writes both `text/html` and `text/plain` to clipboard so paste into Medium / Notion / Google Docs preserves headings, bold/italic, lists, blockquotes, code, and links
- [ ] `.md` clipboard copy
- [ ] MD download
- [ ] TXT download (stripped of markdown chars)
- [ ] Preview (rich HTML render, expandable)

## Bundle exports (per run)

- Combined `.md` (every article concatenated with `---` separators)
- Index `.csv` (title, url, author, summary)
- Raw `.json` (full result payload incl. metadata + search results)
- Links `.txt`
- Titles `.txt`

## 20-test matrix (run sequentially, mark each)

### Beginner (smoke)
1. `keyword=react hooks limit=5` — expect 5 cards, no errors, all have markdown.
2. `keyword=langchain limit=10` — at least 7/10 should have author + read time.
3. `keyword=rust borrow checker limit=8` — verify summary tab is non-empty.
4. `keyword=startup pivot stories limit=10` — at least 1 paywalled post recovered via Archive badge.
5. Click **Copy format** on any card → paste into a Notion page → verify headings & bold survive.

### Intermediate (output fidelity)
6. `keyword=indie hacker mrr report limit=15` — Combined `.md` download opens cleanly in Obsidian.
7. Same run → CSV opens in Excel/Sheets, no broken cells from quotes/newlines.
8. `keyword=postgres tuning limit=12` — Titles `.txt` line count == card count.
9. `keyword=design systems 2025 limit=20` — Live log shows `Step 1/3`, `Step 2/3`, `Step 3/3`, plus per-URL warnings for any failures.
10. Cancel midway by closing the drawer, reopen via Run history → state resumes (run keeps progressing server-side).

### Advanced (stress + edge)
11. `keyword="member-only story" limit=10` — most should trigger Wayback fallback; verify Archive badges appear.
12. `keyword=非常に専門的なAI研究 limit=8` — non-ASCII keyword survives interpolation, results returned.
13. `keyword=climate fintech africa limit=25` — concurrency holds (3 in flight); no rate-limit cascade.
14. `keyword=this-string-has-no-results-xyzqq limit=5` — engine completes with 0 items + `succeeded` status (not `failed`).
15. Disconnect network during scrape → reconnect → realtime catches up and final state is correct.

### Expert (agent reasoning)
16. After a run, open Assistant in a new thread and ask "What were the 3 most original takes in my last Medium run on X?" — assistant should be able to scrape/search to enrich (manual until snapshot results are cross-linked into Assistant context).
17. `keyword=ai agents memory limit=15` — Top-5 must-reads section ranks by depth, not search position.
18. Re-run same keyword 2 hours later — different result set OR same set with refreshed scrape (no stale-cache assumption).
19. Run two snapshots in parallel → both stream progress independently in their own drawers.
20. Delete a snapshot from history → confirm `snapshot_runs` row is gone (RLS-scoped to user).

## Pass criteria

A run is **green** when:
- `status === 'succeeded'`
- `items.length >= 0.7 * limit`
- `summary` is non-empty markdown
- Copy-format produces correctly formatted paste in at least Notion AND Google Docs
- All 5 export buttons download non-empty files

## Known limitations (v1)

- Comment threads are not yet scraped (Medium hides them behind JS state).
- "Most-liked" ranking falls back to search-engine ranking; true claps API is gated.
- Image binaries are referenced by URL, not downloaded.
- Filter UI (title-only vs body-mention, depth bucket) is not yet exposed — currently uses Firecrawl/Google's default ranking.
